# 花之江城 / Wuhan in Bloom — 玩法说明

## 概述

枯潮退去后，1-4名守育者来到武汉的山水浮岛，共同重建生态，也竞争谁能培育出最完整的花朵网络。玩家抽取并打出卡牌，开发地形、修建道路、播种花朵，见证自己的颜色蔓延江城。

---

## 1. 游戏准备

- **人数**：1-4人（开局确定）
- **颜色**：红色、紫色、橙色、深蓝色（每人一种，按座位顺序分配）
- **初始手牌**：每人5张**播种卡**
- **卡堆**：游戏设有**开发卡**、**道路卡**、**天气卡**三个公共卡堆
- **棋盘**：随机生成 **8×8** 地块，中心 **4×4** 为随机植物地块或增益地块，外围四层全部为**山体地块**

---

## 2. 地块类型

### 2.1 植物地块

| 名称 | 外观 | 花朵容积 | 生长率 | 备注 |
|------|------|----------|--------|------|
| 森林 | 深绿 | 100 | 0.5（高） | 最高级 |
| 草地 | 绿色 | 50 | 0.3（中） | |
| 荒漠 | 黄色 | 10 | 0.1（低） | 最低级 |

植物地块可持有花朵，会因相邻地块影响而升级或降级。四名玩家分别使用红色虞美人、紫色风铃草、橙色万寿菊和深蓝色鸢尾花。

### 2.2 增益地块

| 名称 | 外观 | 花朵容积 | 效果 |
|------|------|----------|------|
| 水域 | 蓝色 | 0 | 以自身为中心3×3范围（周围8格）内的植物地块，升级概率翻倍（多个水域不叠加） |
| 建筑 | 红色 | 0 | 永久不被改变；以自身为中心3×3范围（周围8格）内的植物地块，花朵容积翻倍（多个建筑不叠加） |

### 2.3 可开发地块

| 名称 | 外观 | 花朵容积 | 备注 |
|------|------|----------|------|
| 山体 | 灰色 | 0 | 可被开发卡作用 |
| 缺口 | 灰色内凹地块 | 0 | 可被建筑开发卡作用；由山体被包围自动产生 |

> **缺口生成规则**：开发完成后，系统检测由非可开发地块完全包围的内部山体，自动转换为缺口。检测仅在开发卡使用后执行。

> **可开发地块保护**：山体和缺口**不会被极端天气卡改变**（台风、沙尘暴无法将其变为水域/荒漠）。

---

## 3. 回合流程

### 3.1 抽牌
回合开始时，点击左下角**开发卡**、**道路卡**、**天气卡**卡堆，任意组合抽取 **3张卡**。抽满后自动进入出牌阶段。

> **注意**：每回合只从开发/道路/天气卡堆抽牌。播种卡除开局发放外，也可以通过成功开发或闭合道路获得。

### 3.2 出牌
玩家可打出**任意数量**的卡牌（也可以不出牌）。卡牌打出后立即结算效果。

### 3.3 结算
出牌阶段结束后，进入结算阶段（详见第6节）。

### 3.4 回合结束
轮到下一位玩家。

---

## 4. 卡牌详解

### 4.1 播种卡

播种卡只能作用于**花朵未满的植物地块**。增加后花朵总数不超过该地块当前容积。可对同一地块连续打出多张，直到容积满。

| 等级 | 效果 |
|------|------|
| 1级 | 增加10朵花 |
| 2级 | 增加20朵花 |
| 3级 | 增加30朵花 |
| 4级 | 增加40朵花 |
| 5级 | 增加50朵花 |

**使用条件**：
- 目标必须是植物地块（森林/草地/荒漠）
- 花朵总数量 < 地块容积（森林100、草地50、荒漠10；建筑相邻时×2）
- 播种卡有剩余

### 4.2 开发卡

开发卡作用于**山体地块**，将其变为其他地块类型。玩家决定放置位置，地块类型由系统按概率随机生成。使用后外围自动补充山体。

| 等级 | 形状 |
|------|------|
| 1级 | 1×1 单格 |
| 2级 | 1×2 直线两格 |
| 3级 | 三格转弯 L形 |
| 4级 | 2×2方块、Z字形、T字形（三种可选） |

**使用条件**：
- 形状覆盖的所有格子必须是山体
- 至少有一格与已开发地块相邻
- 不越界
- 成功放置后，当前玩家获得 **1张1级播种卡**

**放置预览**：拖出卡牌后，鼠标悬浮位置显示整组地块的半透明预览，Q/E旋转，右键取消。左侧预览栏固定显示地块形状和随机地形预览。

### 4.3 建筑开发卡

| 等级 | 形状 | 效果 |
|------|------|------|
| 1级 | 1×1 | 使缺口变为黄鹤楼建筑 |
| 2级 | 1×2 | 将两个相邻缺口建成洪山科技大厦 |

**使用条件**：形状覆盖的所有格子必须是缺口。不检查相邻条件。成功放置后，当前玩家获得 **1张1级播种卡**。

### 4.4 道路卡

| 等级 | 路径长度 | 连接地块数 |
|------|----------|-----------|
| 1级 | 长度1 | 2个地块 |
| 2级 | 长度2 | 3个地块 |
| 3级 | 长度3 | 4个地块 |

拖出卡牌后在棋盘上按住拖动，路径可转弯，可接入已有道路。松开鼠标建造。

**使用条件**：
- 路径上所有格子不是可开发地块（山体/缺口不能修路）
- 路径连续（相邻格子必须上下左右相邻）
- 可在已有道路上叠加

### 4.5 天气卡

#### 极端天气（持续3回合）

| 名称 | 效果 | 副作用 |
|------|------|--------|
| 台风 | 每回合结束时，每个水域随机将相邻一格变水域（山体/缺口不受影响） | 花朵**生长率减半** |
| 沙尘暴 | 每回合结束时，每个荒漠随机将相邻一格变荒漠（山体/缺口不受影响） | 同上 |
| 雨季 | 所有植物地块**升级概率翻倍** | 同上 |
| 旱季 | 所有植物地块**降级概率翻倍**；每回合结束时，每个水域有概率退化为草地 | 同上 |

#### 正常天气

| 名称 | 效果 |
|------|------|
| 彩虹 | 打出后**立即生效**：消除所有极端天气；花朵**生长率翻倍**，**扩散总概率翻倍** |

**使用条件**：无位置限制。每回合可打出多张天气卡，同类型不叠加。旱季与雨季/台风互斥：打出旱季会移除雨季和台风，打出雨季或台风会移除旱季。彩虹会清除所有极端天气。

---

## 5. 道路地块特性

- 道路连接的地块可以正常结算**花朵增值**
- 道路连接的地块**不参与花朵扩散**（不往外扩散，但可以接收外来花朵）
- 道路**不覆盖建筑地块**：建筑地块上不渲染道路

### 5.1 道路闭合奖励

当一条道路的所有出口都完成连接、整个连通道路中不存在只有一个连接的开放端点，并形成**闭合区域**时：
- 该闭合区域内有花朵的玩家，每人获得 **1张1级播种卡**
- 每条闭合道路只奖励一次（不重复发放）

---

## 6. 结算顺序

每个回合结束时，按以下顺序结算：

### 6.1 结算地块改变

建筑地块、山体、缺口**不会在此环节改变**。

#### 6.1.1 天气导致的地块改变
- 台风：每个水域随机将相邻一格变水域（山体/缺口不受影响）
- 沙尘暴：每个荒漠随机将相邻一格变荒漠（山体/缺口不受影响）
- 旱季：每个水域有概率退化为草地（山体/缺口/建筑不受影响）

#### 6.1.2 植物地块因相邻地块而改变

计算**上下左右四个**相邻地块的影响：
- 每有一个**水域**：升级概率 +20%
- 每有一个**森林**：升级概率 +10%
- 每有一个**草地**：升级概率 +0%
- 每有一个**荒漠**：升级概率 -10%

规则：
- 若总概率 > 0：按该概率**升级一级**（荒漠→草地 或 草地→森林）
- 若总概率 < 0：按该概率**降级一级**（森林→草地 或 草地→荒漠）
- **不能跨级**：荒漠不能直接变森林，森林不能直接变荒漠
- 若相邻有水域地块（3×3范围内），正概率**翻倍一次**（负概率不变，多个水域不叠加）
- **荒漠为最低级**，降级时不变；**森林为最高级**，升级时不变
- **无基础概率**：地块转变完全依赖相邻地块的加成，没有邻居影响则不变

**降级后花朵溢出处理**：
- 森林→草地（容积100→50）：花朵数量减半，下取整
- 草地→荒漠（容积50→10）：花朵数量变为1/5，下取整

### 6.2 结算花朵增值

对每个植物地块：
- **新增花朵** = 原有花朵数量 × 生长率（森林=0.5, 草地=0.3, 荒漠=0.1）
- 若新增后总数超过容积：按 `剩余容积 × (原有花朵 / 原容积)` 取下整数分配
- 极端天气期间生长率减半；彩虹期间生长率翻倍

### 6.3 结算花朵扩散

**条件**：花朵增值后仍有剩余容积的植物地块（有道路的地块不参与扩散）

对每个符合条件的植物地块：
- 计算相邻四个植物地块上**对应颜色花朵的总量**
- 每个相邻地块贡献量 = 该相邻地块对应花朵数量 × 该相邻地块对应花朵数量 / 相邻四个地块总容积 × 扩散概率 × 0.3
- 各相邻地块贡献之和 = 本地块新增扩散花朵数
- 若 `原花朵 + 增值 + 扩散 > 容积`，则按各来源比例缩减，取下整数

---

## 7. 游戏开始

- 随机生成 **8×8** 棋盘
- 中心 **4×4**：按下方概率表随机生成地块类型
- 外围四层：全部为**山体地块**
- 每人发放5张播种卡
- 随机决定先手玩家，按座位顺序轮流进行

### 7.1 地块生成概率

开局中心4×4和开发卡生成地块时，均按以下概率决定地块类型（不含山体）：

| 地块类型 | 概率 | 备注 |
|----------|------|------|
| 森林 | 39% | 最常见的植物地块 |
| 草地 | 28% | |
| 荒漠 | 19% | |
| 水域 | 11% | 增益地块 |
| 建筑 | 3% | 极其稀有 |

---

## 8. 游戏结束

- 总回合数 = 玩家数量 × 10
- 所有回合结束后，统计每人**对应颜色花朵总数**
- 花朵总数最多者获胜
- 平局时，占据植物地块数更多的玩家获胜
