# 蔓延 / GrowCassonne — 玩法说明

## 概述
枯潮退去后，2-4名守育者来到破碎的浮岛，共同重建生态，也竞争谁能培育出最完整的生命网络。玩家选择并放置地形、播种，让植物沿相同生境蔓延。

---

## 基本规则

### 回合流程（每人每回合3步）
1. **选择并放置地形卡** — 从公共市场的3张地形中选1张，放到棋盘空格上
   - 相邻格必须已有地形（第一张除外）
2. **播种（可选）** — 在刚放的地形格上放一颗自己的种子
   - 每人初始5颗种子，每回合+1
3. **生长** — 你的植物自动尝试蔓延到相邻的同类地形；成熟植物会更稳定

### 四种地形
| 地形 | 颜色 | 特点 |
|------|------|------|
| 草地 | 绿色 | 68%基础生长率，1分 |
| 水域 | 蓝色 | 55%基础生长率，1分 |
| 森林 | 深绿 | 42%基础生长率，2分 |
| 荒漠 | 黄色 | 30%基础生长率，3分 |

### 蔓延规则
- 植物只会蔓延到**相邻（上下左右）且同类地形**的格子
- 蔓延率由地形决定；植物每成熟一回合会略微提高成功率
- 每格只能由一名玩家占据，可以用地形布局封锁对手的扩张路线
- 每回合自动触发一次蔓延

---

## 多人模式

### 玩家设置
- 2-4人，每人一个颜色
- 玩家1 = 绿色 | 玩家2 = 蓝色 | 玩家3 = 橙色 | 玩家4 = 紫色

### 轮流机制
- 玩家轮流执行回合
- 每回合：抽地形 → 放地形 → 可选播种 → 触发生长
- 棋盘和种子池是**公共的**（所有玩家共用同一个棋盘）

### 种子分配
- 每位玩家独立计种子数
- 初始5颗，每回合结束+1
- 种子放的是**自己的颜色**

---

## 计分

### 游戏结束条件
- 每位玩家完成10回合后结束（2-4人即总计20-40回合）

### 得分计算
- **生境分**：草地/水域每格1分，森林2分，荒漠3分
- **连片分**：最大连续区域每格2分
- **多样性分**：占据2/3/4种地形时，额外获得3/6/9分

### 胜利条件
- 总分最高的玩家获胜
- 当前得分会在侧栏实时显示
- 平分时，最大连续区域更大的玩家获胜

---

## 策略提示

1. **地形控制** — 别只顾自己，也要阻止对手的连片
2. **种子时机** — 早期多种子建立据点，后期靠蔓延扩张
3. **地形搭配** — 连续放同类地形，为蔓延铺路
4. **阻挡** — 在对手可能蔓延的方向放不同地形
5. **集中 vs 分散** — 一个大大连片 > 多个小小区域

---

## 操作

| 操作 | 按键 |
|------|------|
| 选择地形 | 点击市场卡，或按1/2/3 |
| 放地形 | 左键点击合法空格 |
| 放种子 | 左键点击已放地形格 |
| 跳过播种 | 右键 |
| 重新开始 | R |

---

## 快速开始
1. 打开游戏，点击"开始游戏"
2. 玩家1放地形，可选播种，右键跳过
3. 自动轮到玩家2
4. 重复直到回合用完
5. 看谁的植物连片最大！
