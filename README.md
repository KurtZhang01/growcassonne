# 蔓延 / GrowCassonne — 玩法说明

## 概述
枯潮退去后，2-4名守育者来到破碎的浮岛，共同重建生态，也竞争谁能培育出最完整的生命网络。玩家选择并旋转多格浮岛、连接道路、播种，让植物沿生境与道路蔓延。

游戏场景使用动态程序化天空：多层半透明云缓慢漂移，棋盘下方分布雾海，外围远景浮岛轻微浮动，微光孢子在空间中起伏。背景元素与棋盘保持距离，不影响落点辨识。

---

## 基本规则

### 回合流程（每人每回合3步）
1. **选择并放置浮岛拼图** — 从公共市场的3块随机拼图中选1块
   - 拼图包含2-4格，有双格、直线、L、T、S、方块等形状
   - 按Q/E旋转；整块不能重叠或越界，并且至少一格邻接现有浮岛
2. **播种（可选）** — 在刚放的地形格上放一颗自己的种子
   - 每人初始5颗种子，每回合+1
3. **生长** — 植物自动尝试向相同生境，或道路正确对接的相邻格蔓延

### 道路系统
- 每块随机拼图内部都有连通道路，并生成两个朝外道路口
- 旋转拼图会同时旋转道路；两个相对的道路口相遇后形成跨拼图道路
- 道路允许植物跨越不同地形，并额外提高12%蔓延成功率
- 自己植物占领的每段连续道路连接获得1分
- 新道路成功连接时，桥接处会短暂亮起青色光芒
- 当一条道路的所有出口都完成连接时，道路变为金色并持续脉冲
- 闭合道路上的每个己方植物额外获得2分

### 四种地形
| 地形 | 颜色 | 特点 |
|------|------|------|
| 草地 | 绿色 | 68%基础生长率，1分 |
| 水域 | 蓝色 | 55%基础生长率，1分 |
| 森林 | 深绿 | 42%基础生长率，2分 |
| 荒漠 | 黄色 | 30%基础生长率，3分 |

每格采用分层微缩浮岛模型。地表装饰会避开道路，岩层向下逐级收窄并带有悬垂碎石，使不同拼图连接后仍保持清楚的地形轮廓。

### 蔓延规则
- 植物会蔓延到**相邻且同类地形**，或**道路正确连接**的格子
- 蔓延率由地形决定；植物每成熟一回合会略微提高成功率
- 每格只能由一名玩家占据，可以用地形布局封锁对手的扩张路线
- 每回合自动触发一次蔓延

---

## 多人模式

### 玩家设置
- 2-4人，每人一个颜色
- 玩家1 = 绿色 | 玩家2 = 蓝色 | 玩家3 = 橙色 | 玩家4 = 紫色

### 轮流机制
- 玩家轮流执行回合
- 每回合：选择拼图 → 旋转并放置 → 可选播种 → 触发生长
- 棋盘和种子池是**公共的**（所有玩家共用同一个棋盘）

### 种子分配
- 每位玩家独立计种子数
- 初始5颗，每回合结束+1
- 种子放的是**自己的颜色**

---

## 计分

### 游戏结束条件
- 双人每人10回合、三人每人8回合、四人每人6回合
- 若市场中所有拼图在所有方向都无法放置，游戏会提前结算

### 得分计算
- **生境分**：草地/水域每格1分，森林2分，荒漠3分
- **连片分**：最大连续区域每格2分
- **多样性分**：占据2/3/4种地形时，额外获得3/6/9分
- **道路分**：自己植物占领的每段连续道路连接1分
- **闭合奖励**：闭合道路上的每个己方植物额外2分

### 植物成长
- 新种子从小型破土阶段出现，并带有玩家颜色的生长粒子
- 植物在之后3次生长阶段逐步增高、舒展并轻微摆动
- 到达成熟阶段时再次绽放粒子；成熟后保持稳定尺寸

### 胜利条件
- 总分最高的玩家获胜
- 当前得分会在侧栏实时显示
- 平分时，最大连续区域更大的玩家获胜

---

## 策略提示

1. **道路规划** — 旋转拼图连接道路，可跨越地形扩张
2. **种子时机** — 早期多种子建立据点，后期靠蔓延扩张
3. **拼图选择** — 小拼图容易填补空隙，大拼图能快速拓展版图
4. **阻挡** — 在对手可能蔓延的方向放不同地形
5. **集中 vs 分散** — 一个大大连片 > 多个小小区域

## 操作

| 操作 | 按键 |
|------|------|
| 选择拼图 | 点击市场卡，或按1/2/3 |
| 旋转拼图 | Q / E |
| 放置拼图 | 左键点击合法锚点 |
| 放种子 | 左键点击已放地形格 |
| 跳过播种 | 右键 |
| 重新开始 | R |

---

## 快速开始
1. 打开游戏，点击"开始游戏"
2. 玩家1从市场选择拼图，用Q/E旋转并放置
3. 在空地形格播种，或右键跳过
4. 自动轮到玩家2
5. 重复直到回合用完，建立最大生态与道路网络
