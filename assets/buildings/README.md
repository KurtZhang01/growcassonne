# 建筑资产预览

## 游戏内风格与洪山风物

建筑采用无细描边的纯色色块、两档墙面阴影和较疏窗格，降低原先插画式密集线条的存在感。
草地、森林和有道路的非山体/缺口/建筑地块可以出现洪山主题小装饰：书卷雕塑、竹丛、绿道指路牌。
每个逻辑地块第一次进入对应类别时独立进行 10% 判定，有道路时按道路类别判定，不再同时抽取草地/森林类别。
同一地块同一类别的结果在本局保留，重绘、旋转预览和地块类别往返不会重复抽取。新开局清空。
首次命中时显示金色上浮“发现洪山风物”提示并记录操作历史，无卡牌或数值奖励。
已有地块预览只读取抽取结果，不触发抽取或通知。

打开 `preview.html`。六组建筑各有 0/90/180/270 度四个方向，点击顶部角度按钮切换。

- `isometric/`：24 张透明背景 SVG。
- `references/`：6 张实际下载的建筑照片；`sources.json` 记录页面、原图地址和身份确认程度。
- `generate_buildings.py`：共享投影和建筑结构生成器。运行 `python assets/buildings/generate_buildings.py` 可再生成全部方向。
- 旧的 `hongshan-tower-axis-x.svg` 和 `hongshan-tower-axis-z.svg` 链接保留，内容更新为新投影的 0/90 度版本。

## 识别范围

按用户插画分为：校园牌坊、洪山科创大厦、低层创新园区、红砖山墙楼、白色拱顶场馆、白色框架办公楼。
插画中的游戏手柄、屏幕、奖杯、云图标等为装置，不作为建筑。
洪山科创大厦名称明确；牌坊疑似武汉大学牌坊；红楼参考华中科技大学校园建筑。
园区、场馆和办公楼的确切身份尚未确认。下载照片为标注的候选或类型参考，不能据此声称已确认插画中全部建筑名称。

## 投影和游戏接入

以游戏相机的俯角 42 度、方位角 42 度为基准，使用正交投影；这是贴合棋盘的轴测 2.5D，并非数学上三轴完全等长的 30 度等距图。
屋顶、窗格、地面铺装和牌匾由同一坐标投影，四向资源先旋转建筑坐标再投影。没有图像镜像，中文不会反写。
SVG 为 760×640，180 像素对应 1 个世界单位，地面原点是 (380,486)。
游戏洪山大厦使用四向 Sprite3D，保持深度测试；两个地块的预览均展示完整建筑。
新增五组建筑目前只提供资产预览，未自行增加卡牌、建筑等级或游戏规则。
